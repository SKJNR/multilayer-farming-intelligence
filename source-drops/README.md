# Raw Source Drops

Files in this directory are copied from user-provided text attachments or summaries of AI responses supplied in the conversation.

- `qwen-or-other-ai-initial-architecture.txt`: initial neuro-symbolic / physics-constrained architecture discussion.
- `qwen-synthetic-pipeline-sprint1-initial-report.txt`: early synthetic generator report that included a sampler/test implementation subsequently challenged by review.
- `qwen-sprint1-reexecution-and-sprint2-benchmark-report.txt`: later submitted report describing additional test and benchmark results, including referenced code hashes and claimed logs.
- `qwen-sprint2-closure-typed-in-chat.md`: concise record of the later status update typed directly into the conversation.

These source drops preserve what was submitted, not a warranty of correctness. Refer to the decision records for the current interpretation and verification status. The actual code/log files referenced by some reports were not attached with the text reports in this package.
