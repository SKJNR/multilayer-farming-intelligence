# End-of-session checklist

Before a session can be called complete, check:

- [ ] What decision changed, if any?
- [ ] Which evidence supports the decision? Are sources and artifacts available?
- [ ] Were tests genuinely run? Include exact commands, versions, seed, logs and scenario counts.
- [ ] Are reported results distinguished from independently verified results?
- [ ] Were failures, skips, disagreements and limitations preserved?
- [ ] Was `CURRENT_STATE.md` updated?
- [ ] Was the appropriate decision record created or updated?
- [ ] Were input model responses preserved as raw source drops when relevant?
- [ ] Are the next experiment and acceptance criteria concrete?
- [ ] Is there a commit or a patch that the repository owner can apply?
